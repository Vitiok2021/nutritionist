# Nutritionist

## Опис
Цей проєкт — сайт, створений з метою надання консультацій та порад щодо здорового харчування. Він включає в себе форму для запису на консультацію та інтерфейс для перегляду статей.

## Технології
- HTML5
- SCSS
- JavaScript
- Адаптивна верстка (Flex, Grid)
- Форма з валідацією
- Слайдер для відображення інформації

## Демо
[Live Demo](https://vitiok2021.github.io/nutritionist/) 


## Особливості
- Адаптивна верстка для мобільних пристроїв
- Взаємодія з користувачем через інтерактивні елементи (слайдери, форми)
- Зручний інтерфейс для перегляду статей і порад
